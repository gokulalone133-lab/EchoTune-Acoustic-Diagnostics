EchoTune – Acoustic Diagnostics

AI-powered Motorcycle Engine Fault Detection Android Application

EchoTune is an Android application designed to detect motorcycle engine faults through acoustic analysis.

Features

- Motorcycle engine sound analysis
- Tappet noise detection
- MFCC-based audio feature extraction
- TensorFlow Lite machine learning model
- On-device audio processing

Technology Stack

- Android Studio
- Java/Kotlin
- TensorFlow Lite
- MFCC
- TarsosDSP

Installation

1. Download the EchoTune APK from this repository.
2. Enable installation from unknown sources if required.
3. Install and launch the application.
